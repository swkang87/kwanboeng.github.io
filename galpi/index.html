ND갈피

파일 탐색기 · Windows 10 · 11 전용 · 개발 나든기술 · 무료
설치 파일
불러오는 중…
  1. 위 단추로 설치 파일을 받아 실행합니다(관리자 권한 필요 없음 — 사용자 폴더에 설치).
  2. 「Windows의 PC 보호」 창이 뜨면 추가 정보 → 실행을 누릅니다(아직 코드 서명 인증서가 없어 뜨는 안내입니다).
  3. 바탕 화면·시작 메뉴의 ND갈피로 엽니다. 창을 닫으면 프로그램도 끝납니다(트레이에 남지 않음). Ctrl+N = 새 창.
  4. 새 버전은 ND갈피가 알아서 받아 두고 창 위에 알려 줍니다. 다시 시작을 누르면 적용됩니다.

처음 켤 때

  • 같은 PC 에서 예전에 쓰던 회사 데스크탑 앱의 「탐색기(시험판)」 설정(즐겨찾기 · 사용자 폴더 · 탭 · 창 배치 · 폴더별 보기)이 있으면 한 번 가져오고 알려 줍니다. 원래 설정은 그대로 둡니다.
  • 회사 NAS 같은 조직 설정은 회사 프로그램이 조직 설정 파일을 써 두면 ND갈피를 다음에 켤 때 들어옵니다. 없으면 기본 설정으로 열립니다.
  • 도움말 = 창 오른쪽 위 ? 또는 F1. 프로그램 정보·함께 들어간 소프트웨어의 라이선스는 도움말의 정보.
