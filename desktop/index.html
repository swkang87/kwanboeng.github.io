데스크탑 앱

Windows 10 · 11 전용
설치 파일
불러오는 중…
  1. 위 단추로 설치 파일을 받아 실행합니다(관리자 권한 필요 없음).
  2. 「Windows의 PC 보호」 창이 뜨면 추가 정보 → 실행을 누릅니다(회사 내부 앱이라 서명 인증서가 없어 뜨는 안내입니다).
  3. 설치가 끝나면 앱이 열립니다. 종합정보시스템 아이디·비밀번호로 로그인합니다.
  4. 이후 새 버전은 앱이 알아서 받아 두고 알려 줍니다. 트레이(시계 옆) 아이콘 메뉴 업데이트 후 다시 시작을 누르면 적용됩니다.

「파일」을 쓰려면 — Q-Dir 설치(이미 쓰는 사람은 그대로)

앱 왼쪽 메뉴·트레이 메뉴의 파일을 누르면 PC 의 Q-Dir(창 4개 탐색기)이 회사 기본 배치로 열립니다. NAS 파일은 지금처럼 Z 드라이브(네트워크 드라이브)에서 열고·고치고·저장합니다.
  1. 이미 Q-Dir 을 쓰고 있으면 할 일이 없습니다. 앱이 설치 위치를 알아서 찾습니다.
  2. Q-Dir 이 없으면 Q-Dir 공식 페이지(SoftwareOK)에서 Q-Dir_Installer 를 받아 설치합니다(무료, 관리자 권한 없이 사용자 폴더에 설치됨).
  3. 앱의 파일을 누릅니다. 이미 Q-Dir 창이 열려 있으면 새로 열지 않고 그 창을 앞으로 가져옵니다.
  4. 「Q-Dir 이 설치되어 있지 않습니다」 창이 뜨면 설치한 뒤 다시 확인을 누르거나, 다른 곳에 있다면 직접 찾기로 Q-Dir.exe 를 고릅니다.
Z 드라이브가 안 보이면 관리자에게 문의하세요. 앱 설정(트레이 아이콘 오른쪽 클릭 → 설정)에서 Q-Dir 위치·배치 파일을 바꿀 수 있습니다.
