데스크탑 앱

Windows 10 · 11 전용
설치 파일
불러오는 중…
  1. 위 단추로 설치 파일을 받아 실행합니다(관리자 권한 필요 없음).
  2. 「Windows의 PC 보호」 창이 뜨면 추가 정보 → 실행을 누릅니다(회사 내부 앱이라 서명 인증서가 없어 뜨는 안내입니다).
  3. 설치가 끝나면 앱(바탕 화면·시작 메뉴 ERP)이 열립니다. 종합정보시스템 아이디·비밀번호로 로그인합니다. 예전 이름(「종합정보시스템」)으로 깔려 있던 PC 는 업데이트하면 이름·바로가기가 바뀌고 로그인은 그대로입니다.
  4. 이후 새 버전은 앱이 알아서 받아 두고 알려 줍니다. 트레이(시계 옆) 아이콘 메뉴 업데이트 후 다시 시작을 누르면 적용됩니다.

「파일」을 쓰려면 — ND갈피 설치

앱 왼쪽 메뉴·트레이 메뉴의 파일을 누르면 파일 탐색기 ND갈피가 열립니다(1.4.8~ · 예전 Q-Dir 연결과 「탐색기(시험판)」은 없어졌습니다).
  1. ND갈피 내려받기에서 설치합니다(관리자 권한 필요 없음).
  2. 같은 PC 에서 「탐색기(시험판)」을 쓰던 사람은 ND갈피를 처음 켤 때 즐겨찾기·탭·창 배치가 그대로 들어옵니다.
  3. ND갈피가 없으면 파일을 눌렀을 때 「ND갈피가 설치돼 있지 않아요」 창이 뜹니다 — 설치 페이지 열기를 누르세요.
Q-Dir 은 앱이 건드리지 않습니다. 계속 쓰거나, 필요 없으면 직접 지우면 됩니다. Z 드라이브가 안 보이면 관리자에게 문의하세요.
